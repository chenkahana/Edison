# Product: Edison

## What it is
Edison is a native macOS menu bar app combining:
- Clipboard history
- Screenshot capture
- Lightweight annotation/editing

## Who it is for
People who frequently copy/paste and capture screenshots and want fast, keyboard-first reuse.

## Primary user value
Capture or copy once, find instantly later, and reuse in seconds.

## Core flows
1. **Invoke Hub** via hotkey/menu bar.
2. **Browse/Search** unified history (clipboard + screenshots).
3. **Favorite/Organize** key items.
4. **Re-copy** any item back to clipboard.
5. **Screenshot flow**: capture → immediate editor → copy/save/share.

## Non-goals (MVP)
- Cloud sync/backend
- Accounts/payments
- AI/OCR/collaboration
- Feature gating (MVP is free for everyone)
