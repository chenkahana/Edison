# Working Agreement

1. Read `docs/product.md`, `docs/constraints.md`, and `docs/current-task.md` before coding.
2. Implement only what is inside `docs/current-task.md`.
3. Do not invent scope or refactor unrelated areas.
4. Keep changes minimal, direct, and shippable.
5. If blocked, record blocker + next step in `docs/current-task.md`.
6. When task is complete, update `docs/current-task.md` status.
7. Use `docs/review-checklist.md` before requesting merge.
