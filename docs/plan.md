# Plan

## Phases
1. **Foundation / app shell**
2. **Clipboard core**
3. **Search / organization**
4. **Screenshot capture → editor flow**
5. **Editor tools**
6. **Release hardening**

## MVP (in scope)
- Menu bar app + global hotkey
- Unified Hub UI
- Clipboard monitoring/history
- Search/filter/favorites
- Simple local persistence
- Screenshot capture
- Immediate editor opening after capture
- Lightweight editor MVP
- Copy/save/share basics
- Stable CI, no crashes, no obvious perf regressions

## Later (not now)
- Sync/upload/cloud
- Collaboration
- AI/OCR
- Advanced integrations
