# Edison v1.5 — Manual QA Checklist

Full plan reference: `.omc/plans/edison-1.5.md` (§ 8 Verification Steps).

Execute this checklist on the PR branch before merging. Author initials each item in the PR description (AC13).

## Paste-back (PasteBackCoordinator)
- [ ] Copy text in Safari, open Hub, select item, press Enter — text pastes into Safari
- [ ] Same flow with image item
- [ ] Same flow with file URL item

## Capture (CaptureEngine / CaptureCoordinator)
- [ ] Area screenshot → editor opens → annotate → save
- [ ] Window screenshot → appears in history
- [ ] Full-screen screenshot → appears in history
- [ ] Previous area → re-captures same region

## Search & Filters (SearchEngine + AppState.filteredItems)
- [ ] Type partial query — results filter live
- [ ] Select type filter (text/image/file) — results narrow
- [ ] Select collection — results narrow to collection members

## Editor (EditorWindowView)
- [ ] Open, draw, undo, redo, crop, save, discard

## Settings (SettingsView / SettingsStore)
- [ ] Change history limit — old items trimmed
- [ ] Toggle launch-at-login — state persists across relaunch

## Keyboard Navigation (HubView)
- [ ] Navigate shelf with arrow keys
- [ ] Navigate list with arrow keys
- [ ] Navigate grid with arrow keys

## Quick Look (QuickLookBridge)
- [ ] Select item, press Space — preview appears

## Collections (AppState collection CRUD)
- [ ] Create collection
- [ ] Add item to collection
- [ ] Remove item from collection
- [ ] Delete collection

## Performance (signpost-measurable)
- [ ] Scroll 10k items in list mode — no jank
- [ ] Hub open via hotkey feels same as v1.1

## Stability edges (W5 audit)
- [ ] Quit during paste-back — no crash
- [ ] Repeated capture cycles (10x) — use Instruments Allocations to verify `NSEvent` monitor count returns to baseline after each cycle

## AC7 — performance regression gate
- [ ] Run Instruments os_signpost trace; compare to `docs/performance-baselines.md`
- [ ] p95 hub open ≤ baseline p95 × 1.20
- [ ] p95 search filter ≤ baseline p95 × 1.20
- [ ] p95 history load ≤ baseline p95 × 1.20
- [ ] Record measurements in `docs/performance-baselines.md` post-refactor table
